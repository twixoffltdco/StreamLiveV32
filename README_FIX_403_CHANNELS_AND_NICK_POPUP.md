# Фикс 403 на каналах (Платформа) + история ников как в XenForo

## Почему был 403
Оболочка Платформа открывала каналы ссылками вида `/channel.php?id=123`.
Страница `channel.php` принимала **только** `?slug=...`. Без slug редирект в каталог,
а если канал не `approved` — жёсткий **HTTP 403**.

## Что исправлено

### channel.php
- Принимает `slug`, `id` и `c` (как отдаёт Платформа)
- Владелец / модератор / админ могут открыть свой канал даже если он ещё на модерации
- Остальным по-прежнему 403 на не-approved

### platforma/api_bootstrap.php
- Основные ссылки теперь `/channel/{slug}` (красивый URL)
- Фолбэки: `?slug=`, `?id=`

### platforma/api_channels.php
- В ленту API попадают только `approved` / `active` / `published` каналы
  (чтобы гость не ловил 403 на «сырых» записях)

### profile.php — история ников
- Кнопка «🕘 История ников»
- Всплывающее окно (как в XenForo)
- Закрывается: клик мимо, ×, Escape

## Установка
Распаковать в **корень** сайта поверх существующих файлов.
