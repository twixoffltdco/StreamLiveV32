# Модуль "Видеохостинг" для StreamLive v12

## Что готово и работает
- `sql/videos_schema.sql` — таблицы videos, video_comments, video_likes, video_favorites
- `includes/video_embed.php` — определение платформы по ссылке (YouTube, VK, Rutube, TikTok, Vimeo, Dailymotion, Twitch, Kick, ok.ru, .mp4, .m3u8, generic iframe) + нормализация в embed-URL + автозаполнение title/description/thumbnail через официальный oEmbed (YouTube/Vimeo/TikTok/Dailymotion) с фолбэком на Open Graph теги страницы (VK/Rutube/ok.ru)
- `video_import.php` — форма импорта по ссылке в 2 шага: распознать → показать автозаполненные поля на подтверждение/правку → опубликовать
- `video.php` — страница просмотра: плеер (iframe/video/hls.js/tiktok-embed в зависимости от платформы), лайк, избранное, комментарии, счётчик просмотров
- `video_like.php`, `video_favorite.php`, `video_comment_add.php` — AJAX/POST эндпоинты, сделаны по вашим же паттернам из channel_like.php / comment_add.php

## Как встроить (10-15 минут руками)
1. Залить `sql/videos_schema.sql` через phpMyAdmin/консоль на хостинге
2. Скопировать `includes/video_embed.php` и все `video_*.php` в корень streamlivev12
3. В `channel_manage.php` добавить кнопку "Импорт видео" → ссылку на `/video_import.php?channel_id=ID`
4. Для Twitch-embed заменить `REPLACE_WITH_YOUR_DOMAIN` в `video_embed.php` на реальный домен (Twitch требует parent-параметр)
5. curl должен быть включён в PHP на хостинге (для автозаполнения через oEmbed/OG) — на InfinityFree работает из коробки

## Ограничения, о которых надо знать
- TikTok не даёt embed по ID без их JS-виджета — используется официальный `embed.js`, это нормально и так же делает сам TikTok
- Некоторые площадки (VK иногда, приватные видео) не отдают og:-теги без авторизации — тогда автозаполнение вернёт пустые поля, и пользователь просто заполняет форму руками (это заложено в UI)
- Модерации на импорте сейчас нет (status сразу 'published') — это отдельная задача, см. ниже "Панель модераторов"

| Модуль | Реальный объём | Почему столько |
|---|---|---|
| ✅ Видеохостинг: embed+автозаполнение+лайки/комменты/избранное | сделано выше | — |
| Рекомендации в channel.php/shorts.php по поисковым запросам | 1-2 полноценные сессии | Нужна таблица user_search_log, простая коллаборативная фильтрация или content-based на тегах — YouTube-уровня персонализации не будет физически, но рабочий алгоритм "похожее + твои интересы" — реально |

| Мессенджер со стикерпаками как в Telegram | 1-2 недели | Реалтайм (WebSocket/Socket.io), схема стикерпаков, загрузка/публикация паков, рендер в чате/каналах/комментах — это отдельное приложение внутри платформы |

| Панель модерации каналов/радио (approve/reject/hide) | 1 сессия | У тебя уже есть admin/moderation.php и admin/channels.php — это расширение существующего, не с нуля |

**Итог:** видеохостинг я закрыл сейчас. Геймификация и панель модерации — это по одной сессии каждая, могу делать их следующими без пауз. VK-конструктор и мессенджер это по факту два новых проекта размером со StreamLive каждый — их не "домучать вечером", туда реально нужны дни на каждый, по частям (сначала OAuth, потом деплой, потом каталог — и так же с мессенджером).

Если для обновы сегодня нужен закрытый список — video-hosting из этого архива уже можно грузить.
