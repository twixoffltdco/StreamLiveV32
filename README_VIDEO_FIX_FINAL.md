## Как поставить
Файлы кладутся поверх, пути внутри архива = пути в проекте. Ничего нового в БД заливать не нужно, кроме `sql/migrations/019_videos.sql`, если ещё не заливал.

## Про debug-файл
`moderator_debug.php` — если он показал тебе сырой код вместо результата, значит он открывался не через веб-сервер (например, PHP не настроен на эту папку, либо файл открыли не по http/https-адресу сайта, а как-то иначе — через FTP-просмотр или кэш). Он не обязателен — просто удали его с хостинга, раз модерация и так работает.
