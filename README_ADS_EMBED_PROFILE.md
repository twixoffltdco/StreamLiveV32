# Патч: профиль (бан + кнопки) · реклама в плеерах · авто-embed

## 1. Профиль
- Полный текст при бане: *«Данный пользователь заблокирован… Администрация не несёт ответственности…»*
- Кнопки:
  - 💬 мессенджер
  - 📺 каталог
  - 🔍 скролл к вкладкам
  - ··· меню (история ников, настройки, каналы, рейтинг, форум, видео)

## 2. Реклама в плеерах (как russtube / нашютуб)
Файлы: `includes/player_ads.php`, `admin/ads.php`

- Pre-roll перед контентом
- «Пропустить» через N сек (настраивается)
- После скипа / конца ролика — **cooldown 60 сек** (localStorage), повторно не лезет
- Включено в: `video.php`, `embed.php` (ТВ/радио embed), `channel.php`

Настройки: **/admin/ads.php** (картинка / HTML / mp4, ссылка, skip, cooldown).
По умолчанию **выключено** — включи галкой в админке.

## 3. Авто-подбор локальных embed при импорте
`includes/video_embed.php`:

| Ссылка | Что подставится |
|--------|-----------------|
| smotrim.ru/video/ID | `/playersmotrimru.php?id=ID` |
| любой неизвестный сайт | `/embedwebsite/index.php?url=…&embed=1` |

Новый хендлер: одна запись в `local_embed_providers()` — без правок импорта.

## Установка
Распаковать в **корень** поверх сайта. Ctrl+F5.
Админка → «Реклама в плеерах» → включить и задать креатив.
