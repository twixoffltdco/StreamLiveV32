# Профиль «жидкое стекло» (Telegram-style)

## Что внутри
- `profile.php` — новый UI профиля
- `assets/css/profile-glass.css` — glassmorphism
- `sql/migrations/038_profile_glass.sql` — обложка + статус (опционально)

## Вкладки
| Вкладка | Контент |
|---------|---------|
| Посты | темы форума пользователя |
| Видео | published видео с его каналов |
| ТВ | каналы type=tv |
| Радио | каналы type=radio |
| Ресурсы | resources + broadcast-каналы |

## Действия
- 💬 мессенджер (messages.php?with=id)
- 🕘 история ников (попап, клик мимо / Esc закрывает)
- себе: статус, обложка URL, Gravatar

## Безопасность / устойчивость
- все SELECT в try/catch
- телефон виден только владельцу профиля
- приватные каналы — только себе
- self-healing ALTER для новых колонок; если нет прав — залей 038 вручную

## Установка
Распаковать в корень поверх проекта. Ctrl+F5.
