InfinityFree Daily Hits — что сделано
====================================
Лимит: 50 000 hits / сутки. 1 page view + каждый AJAX = hit.

JS:
- push-notify: опрос раз в 3 минуты, только если вкладка видима
- forum-live: раз в 2 минуты

PHP:
- poll_throttle.php: сервер режет повторные poll с одного IP (45–90 сек)

Что делать тебе:
1. Залить архив поверх сайта
2. Ctrl+F5
3. Не держать открытыми 10 вкладок с чатом/каналом
4. Если hits всё равно летят — временно ОТКЛЮЧИ скрипты в footer:
   закомментируй подключение push-notify.js и forum-live.js
5. Долгосрочно: платный тариф InfinityFree / другой хост (hits не режут так жёстко)

Скрин: 23616/50000 ≈ 47% — ещё есть запас, но к вечеру может упереться.
