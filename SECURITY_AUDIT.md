# StreamLive — краткий аудит (без удаления кода)

## Уже хорошо
- Модерация контента (темы/посты/видео), 2 голоса, нельзя своё
- CSRF на формах (csrf_verify)
- BBCode / sanitize для ников
- Pending не в публичном каталоге

## Проверить руками
1. Админ-пароли, `config.php`, landing `admin_pass`
2. Папка uploads/storage — запрет выполнения PHP
3. Нет бэкапов `.sql` / `.env` в webroot
4. `phpinfo` и debug-страницы закрыть
5. После правок — `php -l` и тест: форум, видео, профиль, модерация

## Ник CSS
- Сохраняется в `users.username_css`
- Рендер только через `user_render_username_html()`
- Простой цвет: `color:#ff00aa` или даже `#ff00aa`
- Тема больше не должна затирать цвет (`!important` на color)

## Не делаем в этом патче
- Жёсткий CSP (сломает inline-скрипты)
- Удаление функций
