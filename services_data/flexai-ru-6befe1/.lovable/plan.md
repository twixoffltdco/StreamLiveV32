# FLEXAI — план реализации

Веб-приложение, оптимизированное под мобильные устройства (PWA), которое работает в России (без блокируемых сервисов). Бэкенд на Lovable Cloud, AI через Lovable AI Gateway (Gemini).

## Дизайн
- Тёмная палитра с акцентом, отличным от GIGA (например, неоновый бирюзово-фиолетовый градиент). Точную палитру согласуем после первого превью.
- Mobile-first (360px), нижняя навигация: Чаты · Создать · Профиль.
- Шрифт: системный sans + акцентный display.

## Основные экраны
1. **Onboarding / Splash** — логотип FLEXAI, кнопки Войти / Регистрация.
2. **Auth** — Email + пароль с подтверждением по email (через Lovable Cloud).
3. **Главная (Чаты)** — список созданных персонажей пользователя + последние сообщения.
4. **Создание персонажа** — имя, описание, личность/стиль речи, аватар (генерация AI или эмодзи), приветственное сообщение.
5. **Чат с персонажем** — стриминг ответов, индикатор печати, баланс монет в шапке, счётчик оставшихся сообщений.
6. **Профиль** — баланс монет, кнопка «Получить ежедневный бонус», статистика, выход.
7. **Docs / FAQ / Условия / Политика конфиденциальности** — статические страницы.

## Экономика монет
- Стартовый баланс: 50 монет.
- Ежедневный бонус: +25 монет (раз в 24 часа, серверная проверка).
- Стоимость:
  - Создание персонажа: 30 монет.
  - 1 сообщение AI: 2 монеты.
- Лимиты (бесплатные, помимо монет):
  - 1 новый персонаж / 24 часа.
  - 5 сообщений / 24 часа.
- Все лимиты и списания проверяются на сервере.

## Бэкенд (Lovable Cloud)

Таблицы:
- `profiles` (id → auth.users, username, coins, created_at)
- `characters` (id, user_id, name, description, personality, avatar_url, greeting, created_at)
- `messages` (id, character_id, user_id, role: user|assistant, content, created_at)
- `daily_claims` (id, user_id, claimed_at) — для бонуса
- `usage_log` (id, user_id, action: create_character|send_message, created_at) — для лимитов 24ч

RLS: пользователь видит и редактирует только свои строки. Роли — отдельная таблица `user_roles` (на будущее, для админки).

Серверные функции (TanStack `createServerFn`):
- `claimDailyBonus` — проверка 24ч, начисление.
- `createCharacter` — проверка лимита 1/24ч, списание 30 монет, insert.
- `sendMessage` — проверка лимита 5/24ч, проверка баланса, списание 2 монеты, вызов AI Gateway (`google/gemini-3-flash-preview`) со стримингом, сохранение пользовательского и ассистентского сообщений.

## AI
- Lovable AI Gateway, модель `google/gemini-3-flash-preview`.
- System prompt собирается из персонажа (имя + описание + личность).
- История сообщений передаётся целиком (контекст диалога).
- Стриминг через `streamText` + `toUIMessageStreamResponse`, рендер через AI Elements.

## Юридические страницы
- `/terms`, `/privacy`, `/docs`, `/faq` — статические маршруты с полным русскоязычным текстом, упоминание FLEXAI как самостоятельного проекта.

## Совместимость с Россией
- Без зависимости от заблокированных сервисов (никаких Google Fonts CDN, reCAPTCHA, Firebase и т.п.).
- Шрифты подгружаем self-hosted либо системные.
- AI и бэкенд работают через Lovable инфраструктуру, доступную из РФ.
- PWA-манифест и сервис-воркер для «установки» на домашний экран.
