# Полные push-уведомления по платформе

## События
| Событие | Кому |
|---------|------|
| Сообщение в мессенджере | Собеседник |
| Ответ в теме форума | Автор темы + кто «следит» |
| Новое видео в канале | Подписчики канала + кто в избранном по видео канала |
| Кнопка «Следить» | channel_subscriptions |

## Как работает
1. Сервер пишет в `notifications`
2. Браузер (если «Разрешить») раз в 20 сек опрашивает `/api_notifications_poll`
3. Показывает системное Notification

**Важно:** без открытой вкладки сайта браузерный push на shared-хостинге без VAPID/Firebase не доходит. С открытой вкладкой (даже в фоне) — работает.

## Установка
В корень → Админка → Обновление БД (миграция 043) → Ctrl+F5  
Войти → Разрешить уведомления → проверить: ЛС, ответ на форуме, импорт видео.
