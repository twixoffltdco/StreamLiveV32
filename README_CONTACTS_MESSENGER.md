# Контакты · ЧС · Жалобы на спам · ТГ-баннер

## Контакты (как Telegram)
- В мессенджере и профиле: **В контакты** / **Удалить из контактов**
- **Телефон в профиле** виден только при **взаимных** контактах (оба добавили друг друга) или себе

## Чёрный список
- **Заблокировать** в чате с незнакомцем и в профиле
- Блок в любую сторону → переписка недоступна
- Из контактов оба вычищаются

## Жалоба на спам
- Кнопка **Спам**
- **10 жалоб от разных пользователей** → автобан на **2 месяца** (severity medium)
- Сроки: weak 14 дней · medium 60 дней · strong 365 дней
- **Админы и модераторы** не банятся

## ТГ-баннер (только стиль Платформа)
- Всегда показывается при входе в сессию
- Есть **×** (скрывает до закрытия вкладки, sessionStorage)
- Ссылка: https://t.me/platforma_offcial

## Установка
Распаковать в **корень**. Миграция: `sql/migrations/039_contacts_blocks_reports.sql`
(таблицы также self-healing в `includes/contacts.php`).
Ctrl+F5.
