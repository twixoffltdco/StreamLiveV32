Рассылки + ресурсы — как мессенджер (жёсткий фикс)
==================================================
В КОРЕНЬ поверх всего. Ctrl+F5 обязательно.

Что изменилось по сути:

1) Рассылки
   - посты грузятся отдельно, авторы — вторым запросом (как диалоги в messages)
   - id поста БОЛЬШЕ НЕ затирается
   - в шапке поста: render_user_badge (аватар + CSS-ник + префиксы + декор + галочка)
   - poll/send/комменты отдают username_html

2) Ресурсы
   - список и страница: тот же render_user_badge
   - SQL с fallback если нет колонок CSS

Если после заливки всё ещё «как раньше» — значит на сервере старые файлы
(кэш opcache). Перезалей и жми Ctrl+F5 / сбрось opcache.
