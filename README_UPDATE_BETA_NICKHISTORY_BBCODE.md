# Обновление: Бета + история ников в профиле + расширенный BBCode

Накладывается **поверх** текущей `stlivefork` — пути внутри архива = пути в проекте.
Ничего из StreamLife не ломает: правки точечные, self-healing уже есть.

## Что сделано

### 1. Платформа: Альфа → Бета
- `platforma/theme-platforma.js` — бейдж «Бета»
- `platforma/theme-platforma.css` — стили `.pl-beta-badge` (+ совместимость со старым классом)
- `platforma/studio/_layout.php` — бейдж «Бета» в студии

### 2. История ников в публичном профиле (как в XenForo)
- `profile.php` — блок «История ников» под статистикой профиля
- Данные из таблицы `username_history` (миграция `034_username_history.sql`)
- Смена ника по-прежнему в `/account_settings.php` (раз в 30 дней)

Если миграция 034 ещё не залита — блок просто не покажется (try/catch), сайт не упадёт.

### 3. BBCode ближе к XenForo
`includes/bbcode.php` — добавлены:
- `[hide]`, `[hide=заголовок]`
- `[spoiler=заголовок]`
- `[user]nick[/user]`, `[user=nick]текст[/user]`
- `[php]…[/php]`, `[html]…[/html]`
- `[align=left|center|right|justify]`
- `[justify]`, `[h1]`, `[h4]`, `[plain]`

`includes/bbcode_toolbar.php` — кнопки: PHP, Hide, Размер, Центр, @user, YouTube

`admin/bbcode_tags.php` — обновлён список зарезервированных имён (чтобы нельзя было переопределить встроенные)

## Установка
1. Распаковать содержимое архива **в корень** сайта (поверх существующих файлов).
2. Убедиться, что залита `sql/migrations/034_username_history.sql` (если ещё нет).
3. Очистить кэш браузера (для CSS/JS бейджа Бета).

## Проверка
- `php -l` на все изменённые PHP-файлы — без ошибок.
- Профиль `/u/username` — если были смены ника, видна история.
- Режим «Платформа» — бейдж «Бета».
- Форум/комменты — новые BBCode-теги рендерятся.

## Не трогали
- Сбор кук с чужих сайтов — **не реализован** (это слежка, незаконно).
- Рекомендации уже работают по cookie истории просмотров видео внутри платформы.
